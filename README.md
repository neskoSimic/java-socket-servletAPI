# Java Socket & Servlet API Project

This project demonstrates the basics of Java socket communication and Java Servlet API development using Apache Tomcat.

## Features

- Basic client-server socket communication
- TCP socket handling in Java
- Java Servlet API usage
- Request and response handling
- Simple backend architecture
- Apache Tomcat integration

## Technologies Used

- Java
- Java Sockets
- Java Servlets
- Apache Tomcat
- IntelliJ IDEA

## Project Structure

- `socket/` - basic socket communication examples
- `servletAPI/` - servlet and API examples
- `src/` - source code

## What I Learned

Through this project I practiced:

- Creating TCP server and client communication
- Working with input/output streams
- Handling HTTP requests in servlets
- Deploying Java web applications on Tomcat
- Understanding backend communication fundamentals
